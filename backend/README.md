# Spring-Boot-Arbeitsbereich

Noch kein generiertes Spring-Boot-Projekt. Vorgesehene Module: identity, servers, operations, console, players, properties, backups, mods, observability und audit. Infrastrukturadapter: Host-Agent, RCON, CurseForge, Restic-Metadaten, Prometheus und Loki. Fachliche Dienste besitzen keine generische exec(String)-Schnittstelle. Dauerhafte Jobs mit serverbezogenen Sperren und Wiederanlaufabgleich zuerst umsetzen.
